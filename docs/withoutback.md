Это критически важное требование для интеграции в профессиональный пайплайн. Чтобы реализовать перенос объектов «без фона» между **Photoshop** и **Dither Yuki**, нам нужно обеспечить полную поддержку **Alpha-канала** (прозрачности) на всех этапах: от импорта до Rust-движка и экспорта.

Вот как мы это реализуем, чтобы сохранить твой **Industrial Flat** стиль и Unix-философию «делать одну вещь идеально».

---

### 1. Поддержка Alpha-канала в Rust (Backend)
Вместо того чтобы работать с цветом как с `RGB`, мы переходим на `RGBA` во всем приложении.

*   **Импорт:** При загрузке PNG с прозрачностью Rust сохраняет 4-й канал.
*   **Дизеринг Прозрачности (Transparent Dithering):**
    *   Алгоритм дизеринга применяется только к пикселям, где `alpha > 0`.
    *   **Вариант А:** Прозрачность остается идеально плавной (как в исходнике).
    *   **Вариант Б (Retro):** Прозрачность тоже дизерится (1-битная маска, как в играх на Sega/PS1), превращая полупрозрачные края в «сеточку» из пикселей.
*   **Маскирование:** Если канал выключен (например, убран Red), прозрачность объекта сохраняется, меняется только цвет видимых пикселей.

### 2. Workflow: Из Photoshop и Обратно
Чтобы художник мог быстро «вернуть без фона», мы добавим специфические функции экспорта.

*   **Поддержка форматов:** Экспорт в **PNG (32-bit)** или **TIFF** с сохранением альфа-канала после всех фильтров.
*   **Padding Control:** При импорте вырезанного объекта Rust может автоматически подрезать пустые края (Crop to Content), чтобы не обрабатывать пустоту, а при экспорте возвращать исходный размер холста для идеального наложения в Photoshop.

### 3. "Clean Room" Rendering
Это режим, при котором фон в превью заменяется на «шахматку» (checkered background), как в Photoshop, чтобы художник видел границы вырезанного объекта.

### Обновленный план реализации для разработчика (.md)

```markdown
# Поддержка прозрачности и Alpha-канала (Transparent Objects)

## 1. Engine (Rust)
- Заменить все структуры пикселей с `Rgb<u8>` на `Rgba<u8>`.
- Обновить `process_frame` так, чтобы алгоритмы квантования игнорировали пиксели с `alpha == 0`.
- Добавить переключатель в настройки дизеринга: 
  - "Smooth Alpha" (сохранение мягких краев).
  - "Binary Alpha" (дизеринг самой прозрачности для retro-look).

## 2. UI (React)
- Добавить поддержку "Checkered Background" (шахматки) на холсте превью.
- В Color Studio добавить отображение Alpha-канала в списке цветов (если используется квантование прозрачности).

## 3. Export
- При экспорте кадра/анимации добавить формат "PNG Sequence with Alpha".
- Реализовать экспорт с сохранением оригинальных метаданных размера (чтобы объект встал на то же место в PS).
```

### Почему это сделает софт «пушкой»:
Художник сможет:
1.  Вырезать персонажа в Photoshop.
2.  Закинуть его в **Dither Yuki**, применить дизеринг и выключить, например, Blue канал для стилизации.
3.  Сохранить как PNG и просто перетащить обратно в Photoshop поверх сложного фона.
4.  **Результат:** Объект выглядит как ретро-спрайт, но идеально вписан в современную композицию.
