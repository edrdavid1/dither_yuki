План реализации работы с GIF

Этап 1: Импорт GIF → Внутренняя анимация 
Первый этап фокусируется на импорте GIF. Вы берёте готовый GIF-файл и превращаете его в свою внутреннюю структуру Animation.
1. Декодирование кадровИспользуйте крейт gif. Настройте ColorOutput::RGBA, чтобы сразу получить данные в нужном формате.
2. Корректная композицияПримените gif-dispose::Screen для правильной отрисовки каждого кадра с учётом disposal-методов. На этом шаге возникает множество тонких моментов — например, один кадр может перекрывать или замещать предыдущий, а флаг прозрачности может быть установлен для всего изображения в целом.
3. Сохранение метаданныхИз каждого кадра извлеките задержку (frame.delay) и информацию о прозрачности (frame.transparent). Сохраните глобальные настройки анимации, например, количество повторов (NETSCAPE2.0 Loop Extension).
4. Передача в UIСформируйте массив Frame — вашу внутреннюю структуру. Уведомите фронтенд, что анимация готова. За основу возьмите существующий таймлайн, который уже используется для видео.

 Этап 2: Применение эффектов 
Интегрируйте кадры GIF в существующий конвейер обработки.
1. Единая модель для GIF, анимации и видеоМодель Animation должна быть единой. Тип исходного файла (GIF, последовательность PNG, видео) не должен влиять на то, как применяются эффекты.
2. Покадровое применение эффектовВаши существующие эффекты (FloydSteinberg, Glitch, Posterize) уже работают с ImageData. Примените их в цикле ко всем кадрам. Поддержите интерактивное выделение нескольких кадров (Shift+Click, Ctrl+Click) и опцию «Применить эффект ко всем кадрам».
3. Сохранение конфигурации в проектеСохраняйте настройки эффектов для каждого кадра в свойстве Animation. Убедитесь, что после сохранения и повторной загрузки проекта все эффекты восстанавливаются.

 Этап 4: Полировка и оптимизация 
После того как базовая функциональность готова, можно заняться улучшениями.
1. Поддержка прозрачностиУбедитесь, что редактор правильно отображает альфа-канал (сетка прозрачности) и что disposal-методы GIF обрабатываются для любого фона. Используйте gif-dispose с готовым фоном или проверяйте логику отображения фона.
2. Предпросмотр в реальном времениПрименение эффектов к GIF должно происходить в фоне с отображением индикатора выполнения для анимации из N кадров.
3. Drag-and-Drop GIFПозвольте перетаскивать GIF в окно приложения.
4. Ассоциация файловАссоциируйте расширение .gif с вашим приложением для быстрого открытия.
