Этап 4. Нагрузочное тестирование и оптимизация
4.1. Тест производительности анимации
* Создать тестовый проект с N кадрами (N = 10, 30, 60, 120, 240).
* Измерить: время применения эффекта ко всем кадрам, FPS предпросмотра, память.
* Определить порог, после которого начинаются тормоза (например, 120 кадров на 1080p).
4.2. Оптимизация
* Кэширование кадров: после применения эффекта к кадру сохранять результат в памяти (в Rust), пока не изменятся его настройки.
* Параллелизация: использовать rayon для обработки кадров анимации (если кадры независимы).
* Ленивый рендеринг: не пересчитывать все кадры при смене эффекта, а только те, которые видны на таймлайне (принцип виртуального скролла).
* Для видео: буферизация декодированных кадров, не хранить всё видео в памяти.
