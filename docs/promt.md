Для того чтобы реализовать систему сохранения проектов `.dyproj` на уровне индустриальных стандартов, мы разобьем процесс на конкретные технические этапы. План построен так, чтобы каждый шаг был проверяемым и независимым.

Ниже представлен детальный план и промты для AI-агентов (Cursor, Copilot, aider).

---

## 🧭 Общая стратегия реализации

Мы внедряем архитектуру **Asset Management System (AMS)**, где проект — это не просто JSON, а интеллектуальный контейнер. Основные компоненты:
1.  **Манифест (JSON)** — логика, структура слоев, настройки цвета и метаданные.
2.  **Бинарный блок (Bincode)** — тяжелые данные анимации (кейфреймы), требующие высокой скорости чтения.
3.  **Система Relink** — каскадный поиск ассетов по хэшам и путям.

---

## 📋 Этап 1: Структуры данных (Manifest & Types)

**Цель:** Синхронизировать Rust-бэкенд и TS-фронтенд через единую схему.

### Промт для Rust (types.rs):
> «Создай модуль `src-tauri/src/project/types.rs`. Определи структуру `DyprojManifest` и вложенные структуры (Layer, Palette, AssetRecord). Используй `serde` с атрибутами `#[serde(deny_unknown_fields)]` и `#[serde(rename_all = "camelCase")]`. Поле `version` должно быть обязательным. Напиши тест, который проверяет десериализацию JSON-манифеста с вложенными массивами слоев и анимационных треков.»

### Промт для TypeScript (project.ts):
> «Создай файл `src/types/project.ts` с интерфейсами, которые зеркально отражают Rust-структуры из `types.rs`. Создай отдельный файл `src/validation/validateManifest.ts`, использующий библиотеку `ajv` для валидации объекта манифеста перед отправкой на бэкенд. Схема должна поддерживать UUID v4 для всех ID объектов.»

---

## 📋 Этап 2: Хэширование и Умные Ассеты

**Цель:** Реализовать логику `storage: "auto"` и идентификацию файлов.

### Промт для Rust (assets.rs):
> «Реализуй в `src-tauri/src/project/assets.rs` функцию `compute_asset_hash(path: &Path)`. Логика: если файл < 100 МБ, считать SHA-256 полностью. Если > 100 МБ — читать первые 10 МБ, последние 10 МБ и размер файла, конкатенировать их и брать хэш от этой строки (для скорости). Также создай функцию `determine_storage_mode(size_bytes: u64)`, которая возвращает `Embedded` для файлов меньше 10 МБ и `External` для остальных.»

---

## 📋 Этап 3: Команда сохранения (ZIP-контейнер)

**Цель:** Атомарное создание файла `.dyproj`.

### Промт для Rust (commands/save.rs):
> «Реализуй Tauri-команду `save_project`. Аргументы: путь сохранения, объект манифеста, бинарные данные таймлайна.
> 1. Создай временную папку.
> 2. Скопируй все `embedded` ассеты в подпапку `assets/`.
> 3. Запиши `manifest.json` и `timeline.bin`.
> 4. Создай ZIP-архив (крейт `zip`, метод `Stored`) и сохрани его по целевому пути.
> 5. Реализуй атомарность: сначала пиши во временный `.tmp` файл, затем переименовывай в `.dyproj`.»

---

## 📋 Этап 4: Загрузка и Relink (Media Offline)

**Цель:** Восстановление связей с файлами при открытии.

### Промт для Rust (commands/load.rs):
> «Реализуй Tauri-команду `load_project`. После распаковки `manifest.json` запусти процесс `relink_assets`. Для каждого внешнего ассета: 
> 1. Проверь `original_path`. 
> 2. Если файл потерян, поищи файл с таким же именем в папке с `.dyproj`. 
> 3. Если не найден, выполни поиск по хэшу в базе данных кэша приложения. 
> 4. Если всё провалено, верни ассет со статусом `offline: true`.»

---

## 📋 Этап 5: Custom Protocol для видео-стриминга

**Цель:** Проигрывание видео напрямую из архива/диска.

### Промт для Rust (main.rs):
> «Зарегистрируй кастомный URI-протокол `dyproj://`. Обработчик должен принимать `asset_id`, находить путь к файлу через менеджер ассетов и поддерживать HTTP Range-запросы (заголовок `Range`). Возвращай `206 Partial Content`, чтобы видеоплеер в браузере мог перематывать видео без полной загрузки файла в память.»

---

## 📋 Этап 6: Undo/Redo и Dirty State (Frontend)

**Цель:** История действий и отслеживание изменений.

### Промт для React (Zustand):
> «Настрой middleware `zundo` для Zustand-стора. Исключи из истории тяжелые бинарные данные. Реализуй хук `useDirtyCheck`, который сравнивает хэш текущего манифеста с хэшем последнего сохраненного. Добавь `setInterval` на 5 минут для вызова команды `auto_save` во временную директорию ОС.»

---

## 📋 Этап 7: Поддержка Alpha и RGB каналов

**Цель:** Профессиональная работа с цветом и прозрачностью.

### Промт для Rust (image_engine):
> «Обнови пайплайн обработки: 
> 1. Используй `Rgba<u8>` вместо `Rgb<u8>`. 
> 2. Добавь структуру `ChannelMask { r: bool, g: bool, b: bool, a: bool }`. 
> 3. В цикле квантования пикселей, если канал выключен в маске, приравнивай его значение к 0. 
> 4. Убедись, что при экспорте в PNG альфа-канал сохраняется, если включен режим 'Keep Alpha'.»

## ✅ Резюме для разработчика
*   **Стек:** Rust (Tauri), TypeScript (React/Zustand).
*   **Ключевые крейты:** `zip`, `bincode`, `serde`, `sha2`, `tempfile`.
*   **Главный приоритет:** Неразрушающее редактирование (храним оригинал + список изменений).

Этот план закрывает все потребности профессионального рабочего процесса: от безопасности данных до интеграции с Photoshop через прозрачные PNG. Выполнять этапы рекомендуется строго по порядку.
